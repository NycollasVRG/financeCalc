# UI Rules

- Use **shadcn/ui** components exclusively for all UI elements.
- Do **not** create custom components when a shadcn/ui component exists or can be installed.
- If no suitable shadcn/ui component is available, check the [shadcn/ui registry](https://ui.shadcn.com/docs/components) and install the appropriate one before proceeding.
- Do not install new shadcn/ui components unless needed for the current task.
